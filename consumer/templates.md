# 消费与互联网 · 文书模板

> 仅供参考；各地市场监管部门 / 法院格式可能不同。

---

## 模板 1：12315 投诉陈述（可粘贴至全国 12315 平台或线下登记）

```text
投诉人：姓名________ 电话________ 地址________
被投诉人：名称/姓名________ 地址________ 电话________
（如有平台：平台名称________ 店铺名________ 订单号________）

消费时间：____年__月__日
消费金额：________元
商品/服务：________
购买渠道：□线下 □网购平台 □直播 □预付卡/会员 □其他

投诉请求：
1. 退还货款/服务费________元；
2. 依照《消费者权益保护法》第五十五条第一款增加赔偿________元（或依照《食品安全法》第一百四十八条第二款支付惩罚性赔偿金________元）；
3. 其他：________

事实与理由：
……（时间线：下单/付款、宣传承诺、收货、问题发现、与商家/平台沟通结果）。
本人为生活消费需要购买。认为被投诉人存在________（欺诈 / 不符合质量要求 / 不符合食品安全标准 / 拒绝七日无理由退货等）情形。

证据清单：订单截图、支付记录、聊天记录、发票/小票、检测或鉴定材料、宣传页面截图等。

投诉人：________
日期：____年__月__日
```

## 模板 2：民事起诉状（信息网络买卖合同纠纷 / 产品责任纠纷等）

```text
民事起诉状

原告：姓名：________ 性别：__ 民族：__ 出生日期：________
身份证号：________________ 住址：________________ 电话：________

被告一：________（经营者名称/姓名） 住所地：________ 统一社会信用代码/身份证号：________
被告二（如有）：________（电子商务平台经营者） 住所地：________

案由：信息网络买卖合同纠纷 / 买卖合同纠纷 / 产品责任纠纷（择一或按法院要求）

诉讼请求：
一、判令被告退还原告货款人民币________元，原告同时退还商品（如需）；
二、判令被告支付惩罚性赔偿金人民币________元
   （计算：□消保法§55：max(3×价款,500)；□食安法§148：max(10×价款,1000)；基数与假设：________）；
三、判令被告赔偿其他损失________元（运费、检测费、医疗费等，附清单）；
四、诉讼费用由被告负担。

事实与理由：
……（生活消费目的、购买经过、商品问题、欺诈或不符食品安全标准的事实、平台责任线索）。
依据《中华人民共和国消费者权益保护法》第二条、第二十五条、第四十四条、第五十五条，《中华人民共和国食品安全法》第一百四十八条（如适用），《中华人民共和国电子商务法》第三十八条（如适用），以及《最高人民法院关于审理网络消费纠纷案件适用法律若干问题的规定（一）》等相关规定，提起诉讼。

证据目录：……

此致
________人民法院

具状人：________
日期：____年__月__日
```

```text
联系人：________ 电话：________
日期：____年__月__日
```
