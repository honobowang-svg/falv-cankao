# 民事·物权/不动产 · 期限与时效

| 事项 | 规则 | 依据 |
|------|------|------|
| 期房办证替代期限 | 交付使用之日起90日（合同无约定时） | 商品房买卖解释§18 |
| 现房办证替代期限 | 合同订立之日起90日 | 同上 |
| 迟延履行解除催告 | 催告后合理期限（解释明确可支撑3个月）仍未履行可解除；解除权除斥等见§15 | 解释§15；民法典§563 |
| 异议登记 | 登记机构予以异议登记；申请人在异议登记之日起**十五日内**不提起诉讼，异议登记失效 | 民法典§220 |
| 优先购买权行权 | 其他按份共有人收到通知后**十五日内** | 物权编解释§12 |
| 一般诉讼时效 | 三年 | 民法典§188 |

### 对用户的话术

> 「异议登记后请在十五日内起诉，否则异议登记失效。办证期限注意合同约定与90日替代规则。本提醒仅供参考。」
