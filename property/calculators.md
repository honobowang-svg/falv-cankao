# 民事·物权/不动产 · 计算器

## 1. 逾期交房违约金

### 有约定
按合同约定的违约金或计算方法；过分高于损失的，对方可请求适当减少（参考商品房买卖解释§16：以超过损失30%为减少参考标准）。

### 无约定（解释§17）
逾期交付使用房屋的，可按照逾期期间有关主管部门公布或有评估资质机构评定的**同地段同类房屋租金标准**确定。

`建议索赔额 ≈ 日租金 × 逾期天数`（或月租金/30 × 天数）

### 示例 A
合同约定2024-06-30交房，实际2024-09-28（逾期90天）；评估同地段月租6000元。  
无约定违约金时参考：`6000/30×90 = 18,000` 元。

## 2. 逾期办证违约金

### 有约定
从约定。

### 无约定（解释§18）
由于出卖人原因，买受人在约定期限或法定替代期限届满未能取得权属证书的，可按**已付购房款总额**，参照中国人民银行规定的金融机构计收**逾期贷款利息**标准计算。

替代期限提醒：
- 期房：自房屋交付使用之日起**90日**；
- 现房：自合同订立之日起**90日**；
- 或合同另行约定的办证期限。

> 计息标准请以合同履行期间有效的金融机构逾期贷款利率规则及裁判口径为准；表述变化时标【待核实】。

### 示例 B
已付房款1,000,000元，逾期办证365天；若裁判参照年利率 L（示意），则  
`违约金 ≈ 1,000,000 × L × 365/360`（具体日计数与利率口径依法院地实践）。

## 3. 面积误差比 3% 规则（《商品房销售管理办法》§20）

`误差比 R = (登记面积 - 约定面积) / 约定面积 × 100%`

| 情形 | 处理 |
|------|------|
| \|R\| ≤ 3% | 据实结算房价款 |
| \|R\| > 3% | 买受人有权退房（退房则退款+利息，30日内） |
| 不退房且登记>约定 | ≤3%部分补差价；**>3%部分房款由开发商承担，产权归买受人** |
| 不退房且登记<约定 | ≤3%部分退差价；**>3%部分房款由开发商双倍返还** |

### 示例 C
约定100㎡，登记104㎡ → R=4%。不退房：  
- 3㎡（3%）内：买受人补 `(3/100)×总价`；  
- 超出的1㎡：房款由出卖人承担，产权归买受人。

### 示例 D
约定100㎡，登记96㎡ → R=-4%。不退房：  
- 3㎡内差价返还；  
- 超出的1㎡对应房款**双倍返还**。

## 4. 对用户的话术

> 「请提供合同约定的交房日、办证日、面积计价方式与实测报告。逾期交房无约定时可参考同地段租金；逾期办证无约定可参照已付款的逾期贷款利息标准。面积误差以3%为关键线。本计算仅供参考。」
