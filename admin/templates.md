# 行政 · 文书模板（骨架）

---

## 1. 行政复议申请书

```
行政复议申请书

申请人：姓名/名称、住所、联系方式
被申请人：行政机关名称、住所

行政复议请求：
1. 撤销（或变更）被申请人于____年__月__日作出的________决定；
2. ……

事实与理由：
（简述行政行为内容、知悉时间、违法或不当之处）

此致
________（行政复议机关）

申请人：________
日期：________
附件：身份证/主体资格、行政行为文书、证据材料
```

---

## 2. 行政起诉状

```
行政起诉状

原告：……
被告：行政机关……

诉讼请求：
1. 撤销被告作出的________；
2. ……

事实与理由：
（是否经过复议、复议结果、起诉期限起算）

此致
××人民法院

起诉人：________
日期：________
```

---

## 3. 政府信息公开申请

```
政府信息公开申请表（自拟骨架）

申请人：……
申请公开的政府信息：（描述文件名称、文号或内容要素，尽量明确）
获取方式：邮寄 / 电子邮件 / 现场查阅
联系方式：……

申请人：________
日期：________

提示：对不予公开不服的，依法先申请行政复议。
```
