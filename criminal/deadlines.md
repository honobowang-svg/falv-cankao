# 刑事 · 期限速查

| 事项 | 期限 | 依据 |
|------|------|------|
| 拘留后送看守所 | 至迟24小时 | 刑诉法§85 |
| 拘留后讯问 | 24小时以内 | §86 |
| 一般提请批捕 | 拘留后3日（可延1–4日；流窜等至30日） | §91 |
| 检批捕决定 | 7日以内 | §91 |
| 逮捕后侦查羁押 | 2个月（可依法延长） | §156等 |
| 律师会见安排 | 至迟48小时 | §39 |
| 申请变更强制措施答复 | 3日以内 | §97 |
| 取保候审 | 最长12个月 | §79 |
| 监视居住 | 最长6个月 | §79 |
| 不服判决上诉 | 10日 | §230 |
| 醉驾快速办理（符合条件） | 立案侦起约30日内侦诉审 | 2023意见§23 |

### 话术
> 「以上为法定期限节点，个案以办案机关文书为准。请尽快委托律师核对是否超期羁押、可否变更强制措施。」
