# 刑事 · 文书模板

> 仅供参考骨架；提交前由执业律师审定。禁止利用模板作虚假陈述。

---

## 模板 1：取保候审申请书

```text
取保候审申请书

申请人：________（犯罪嫌疑人/被告人近亲属或辩护人）  
被申请人/办案机关：________公安局 / ________人民检察院 / ________人民法院  
犯罪嫌疑人（被告人）：________ 性别：__ 出生日期：________  
涉嫌罪名：________ 羁押处所：________

申请事项：
对犯罪嫌疑人（被告人）________变更强制措施为取保候审。

事实与理由：
1. 本案情况简述（时间、阶段、强制措施种类）……
2. 符合《刑事诉讼法》第六十七条之情形：（勾选并说明）
   □ 可能判处管制、拘役或独立适用附加刑；
   □ 可能判处有期徒刑以上刑罚，取保不致发生社会危险性；
   □ 患严重疾病/生活不能自理/怀孕或哺乳，取保不致发生社会危险性；
   □ 羁押期限届满，案件尚未办结，需要取保候审。
3. 保证方式：□保证人________ / □保证金________元。
4. 申请人知悉被取保候审人应遵守刑诉法第七十一条等规定。

此致
________（决定机关）

申请人签名：________
日期：________
附件：身份证明、亲属关系证明、病情资料、辩护委托手续等
```

## 模板 2：刑事控告 / 报案材料

```text
控告（报案）书

控告人（报案人）：________ 身份证号：________ 住址/电话：________  
被控告人（嫌疑人，如有）：________ 身份信息（知悉范围内）：________

请求：
请贵机关依法立案侦查，追究相关人员刑事责任。

事实与理由：
……（时间、地点、人物、经过、结果；避免主观臆测）

证据清单：
1. …… 2. ……

控告人声明：所控内容如有诬告，愿负法律责任；所述如有出入但非故意捏造，请与诬告区分。

此致
________公安局 / ________人民检察院 / ________人民法院

控告人签名：________
日期：________
```

## 模板 3：谅解书（被害人出具）

```text
谅解书

谅解人（被害人）：________  
被谅解人：________ 案由：________

本人就________一案，发表如下意见：
一、被谅解人已赔偿/正在履行赔偿……（金额与凭证）。
二、被谅解人已赔礼道歉，本人表示谅解，请求办案机关在法律规定范围内予以从宽处理（是否同意缓刑等由司法机关依法决定，本人不代替裁判）。
三、本人作出本谅解书意思真实，未受胁迫。

谅解人签名：________
日期：________
（可公证或由律师见证；涉及刑事和解程序的，还应符合刑诉法当事人和解章节条件）
```
