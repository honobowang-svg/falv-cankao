# 劳动与社保 · 时效与期限提醒

> 核心依据：`《劳动争议调解仲裁法》第27、43、47–50条`；`《工伤保险条例》第17、20、26条` 等（已核实原文见 knowledge_base）。

---

## 1. 劳动争议仲裁时效（最重要）

| 规则 | 内容 |
|------|------|
| 普通时效 | **一年**，自知道或应当知道权利被侵害之日起算 |
| 中断 | 向对方主张权利 / 向有关部门请求救济 / 对方同意履行 → 重新计算 |
| 中止 | 不可抗力或其他正当理由 → 原因消除后继续计算 |
| 拖欠劳动报酬 | **劳动关系存续期间**不受一年限制；**终止后**须自终止之日起一年内提出 |

**实操提醒**：解除补偿、违法解除赔偿金等，通常从解除/终止日或应支付日起敏感起算；尽早申请仲裁。

---

## 2. 仲裁审理期限

- 受理后一般 **45 日内**结束；复杂经批准可延长，延长期限不得超过 **15 日**。  
- 逾期未裁决的，当事人可就该争议事项向人民法院提起诉讼。

---

## 3. 对裁决不服的起诉 / 撤销

| 情形 | 期限 |
|------|------|
| 劳动者对终局裁决不服起诉 | 收到裁决书之日起 **15 日内** |
| 用人单位申请撤销终局裁决 | 收到裁决书之日起 **30 日内**（中级法院，法定事由） |
| 非终局裁决双方起诉 | 收到裁决书之日起 **15 日内** |
| 期满不起诉 | 裁决书发生法律效力 |

---

## 4. 工伤认定申请

| 主体 | 期限 |
|------|------|
| 用人单位 | 事故伤害发生日或职业病诊断鉴定之日起 **30 日内**（特殊情况可延长） |
| 职工/近亲属/工会 | 用人单位未申请的，自事故或诊断鉴定之日起 **1 年内** 可直接申请 |
| 单位逾期未申请 | 此间符合规定的工伤待遇费用由**该用人单位**负担 |

社会保险行政部门受理后一般 **60 日内**作出认定；事实清楚的可 **15 日**。

---

## 5. 劳动能力再次鉴定

对设区的市级鉴定结论不服：收到鉴定结论之日起 **15 日内**向省级劳动能力鉴定委员会申请再次鉴定（最终结论）。

---

## 6. 其他常见期限（问答时提示）

| 事项 | 期限 | 依据提示 |
|------|------|----------|
| 劳动者预告解除 | 提前 **30 日**书面；试用期提前 **3 日** | 劳动合同法§37 |
| 无过失辞退预告 | 提前 **30 日**书面或代通知金 | 劳动合同法§40 |
| 出具解除证明 / 社保转移 | 解除终止时出具证明；**15 日内**办档案和社保转移 | 劳动合同法§50 |
| 集体合同异议期 | 劳动行政部门收到文本 **15 日内**未异议则生效 | 劳动合同法§54 |

---

## 7. 对用户的话术模板

> 「劳动争议申请仲裁时效一般为一年；若已离职，请核实离职日是否已接近一年。建议在时效届满前向劳动合同履行地或用人单位所在地劳动争议仲裁委员会提交申请。本提醒仅供参考，请咨询执业律师并核对当地口径。」


---

## 8. 民事诉讼时效（与劳动仲裁时效的关系）

劳动争议**仲裁**时效适用《劳动争议调解仲裁法》第二十七条（一年等，见上文），属「法律另有规定」。  
对仲裁裁决不服起诉、或纯属民事请求（非劳动争议受案范围）时，适用《民法典》第一百八十八条–第一百九十九条（普通诉讼时效三年、中止中断、最长二十年等）。**全文已核实收录于 `consumer/deadlines.md` 第4节，labor 库同步引用。**  
《民法典》第一百九十八条：法律对仲裁时效有规定的，依照其规定；没有规定的，适用诉讼时效的规定。
