# 民事·合同 · 文书模板

> 仅供参考；各地法院格式可能不同。不构成律师函。

---

## 模板 1：履行催告函

```text
履行催告函

致：________（对方姓名/名称）
地址：________ 联系电话：________

催告人：________ 地址：________ 电话：________

事实简述：
双方于____年__月__日签订《________合同》（合同编号：________），约定贵方应于____年__月__日前履行________义务（给付价款/交付标的物/返还借款本息等）。截至本函出具之日，贵方仍未履行 / 未完全履行。

催告事项：
请贵方自本函送达之日起____日内（合理期限）履行下列义务：
1. ________；
2. ________。

法律后果提示：
若逾期仍不履行，催告人将依据《中华人民共和国民法典》第五百六十三条等规定依法解除合同，并追究违约责任（违约金/定金罚则/损害赔偿等），保留提起诉讼或申请仲裁的权利。

证据目录（复印件）：合同、付款/交货凭证、往来函件等。

催告人（签章）：________
日期：____年__月__日
```

## 模板 2：合同解除通知书

```text
合同解除通知书

致：________

通知人：________

通知人与贵方于____年__月__日签订的《________合同》（编号：________），因下列事由：
□ 不可抗力致使不能实现合同目的；
□ 贵方明确表示或以行为表明不履行主要债务；
□ 贵方迟延履行主要债务，经____年__月__日催告后在合理期限内仍未履行；
□ 贵方违约致使不能实现合同目的；
□ 约定解除条件成就：________；
□ 其他：________。

现依据《中华人民共和国民法典》第五百六十三条、第五百六十五条等规定，通知解除上述合同。
□ 合同自本通知到达贵方时解除；
□ 若贵方未在____年__月__日前履行________，则期限届满时合同自动解除。

请贵方于解除后____日内办理返还财产、结清价款、移交凭证等事宜。通知人将依法主张违约责任与损失赔偿。

如对解除有异议，可依法请求人民法院或仲裁机构确认解除行为的效力。

通知人（签章）：________
日期：____年__月__日
送达方式：□邮寄□电子邮件□当面□其他________
```

## 模板 3：民事起诉状（合同纠纷）

```text
民事起诉状

原告：姓名/名称：________ 住所地：________ 联系电话：________
（法人）法定代表人：________ 统一社会信用代码：________

被告：姓名/名称：________ 住所地：________ 联系电话：________

案由：买卖合同纠纷 / 民间借贷纠纷 / 房屋租赁合同纠纷 / 承揽合同纠纷 / 委托合同纠纷（择一）

诉讼请求：
一、判令被告继续履行合同 / 支付价款（或返还借款本金）人民币________元；
二、判令被告支付利息 / 逾期利息人民币________元
   （计算：本金________，利率____%〔未超过合同成立时一年期LPR四倍〕，起止________，公式见附件）；
三、判令被告支付违约金人民币________元（或适用定金罚则：________）；
   （若请求违约金：损失约________元；违约金未过分高于损失／或请法院依法调整）；
四、判令被告赔偿损失人民币________元（清单附后）；
五、诉讼费用由被告负担。

事实与理由：
……（订立、履行、违约、催告与解除过程）。
依据《中华人民共和国民法典》相关条文（如第五百七十七条、第五百八十五条、第五百八十六条、第六百六十七条等），《最高人民法院关于适用〈中华人民共和国民法典〉合同编通则若干问题的解释》第____条，以及《最高人民法院关于审理民间借贷案件适用法律若干问题的规定》第____条（如适用）等，提起诉讼。

证据目录：……

此致
________人民法院

具状人：________
日期：____年__月__日
```
