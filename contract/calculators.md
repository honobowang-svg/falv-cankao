## 1. 民间借贷利率司法保护上限（LPR×4）

**依据**：民间借贷规定（2020修正）第二十六条、第二十九条、第三十条；民法典第六百八十条。

### 公式

1. 确认属于民间借贷（非持牌金融机构贷款业务）。  
2. 查**合同成立时**一年期 LPR = `L`（年利率，小数或百分数一致口径）。  
3. **保护上限年利率 `Cap = 4 × L`**。  
4. 约定利率 `R`：`R > Cap` 的部分，出借人请求支付的，法院一般不予支持。  
5. 逾期利息、违约金及其他费用**合计**亦不得超过 `Cap`（第三十条）。

### 快照示例（假设合同成立日适用 2026-10-20 的一年期 LPR）

- `L = 3.00%` → **`Cap = 12.00%` / 年**  
- 本金 `P = 100,000` 元，借期 1 年，约定利率 24% → 法院一般最多支持按 **12%** 计息 → 利息上限约 **12,000 元**（单利、满一年、未还本）。

> 若合同成立于其他月份，必须改用该月一年期 LPR 重算。

## 2. 逐期利息（单利）

**依据**：民法典借款合同章；民间借贷规定第二十五条–第三十一条。

### 公式（按日计息常见写法）

1. 年利率 `R`（已裁至不超过 `Cap`）。  
2. 日利率 `r = R / 360` 或 `R / 365`（**写明假设**；合同有约定从约定；司法实践口径可能不同）。  
3. 第 `i` 期：本金 `P_i`（若未还本则常为初始本金）、天数 `D_i`。  
4. **期利息 `I_i = P_i × r × D_i`**。  
5. **总利息 `I = Σ I_i`**；本息合计注意第二十八条「最初本金 + 全程按 Cap 计息」封顶（存在滚动计息/重新出具借条时）。

### 示例 A（整年单利）

- P=100,000；R=12%（=Cap）；期限 365 天；按 `R/365`  
- I = 100000 × 0.12 × (365/365) = **12,000 元**

### 示例 B（两期）

- P=100,000；R=12%；第1期 90 天、第2期 90 天；按 `R/360`  
- I1 = 100000 × 0.12 / 360 × 90 = **3,000**  
- I2 = 同上 **3,000**  
- I = **6,000 元**

### 无利息约定

- 未约定利息：出借人主张借期内利息 → 一般不予支持（第二十五条第一款）。  
- 自然人之间约定不明：视为没有利息（第二十五条第二款；呼应民法典§680）。

## 3. 违约金调整（过分高于损失 → 超损失 30%）

**依据**：民法典第五百八十五条；法释〔2023〕13号第六十四条、第六十五条。

### 公式 / 规则

1. 违约造成的损失 `Loss`（以民法典第五百八十四条为基础，含合同履行后可获得的利益，但受可预见规则等约束）。  
2. 约定违约金 `D`。  
3. 若 `D > Loss × 130%`（即超过损失的**百分之三十**），法院**一般可以**认定为「过分高于造成的损失」，依申请适当减少（解释§65第二款）。  
4. 仍须综合合同主体、交易类型、履行情况、过错、履约背景等，公平诚信衡量；**恶意违约**方请求减少的，一般不予支持（§65第三款）。  
5. 调整须当事人请求（反诉或抗辩）；仅以防调条款排除调整的，不予支持（§64）。

### 示例 C

- Loss = 10,000 元；约定 D = 20,000 元  
- Loss × 130% = 13,000  
- D > 13,000 → **一般可认定过分高于损失**，存在调减空间（最终以裁判衡量为准，不是自动改判为 13,000）。

### 示例 D

- Loss = 10,000；D = 12,000  
- 12,000 ≤ 13,000 → **一般不仅因「30% 规则」认定为过分高于**（仍可能结合其他因素）。

## 4. 定金上限（不超过主合同标的额 20%）

**依据**：民法典第五百八十六条、第五百八十七条、第五百八十八条；法释〔2023〕13号第六十七条、第六十八条。

### 公式

1. 主合同标的额 `S`。  
2. 约定定金 `Dep`：**超过 `0.2 × S` 的部分不产生定金效力**。  
3. 生效定金以**实际交付**为准；实际交付多于或少于约定的，视为变更约定数额。  
4. 违约定金罚则：给付方违约 → 无权请求返还；收受方违约 → **双倍返还**。  
5. 定金与违约金：**只能择一适用**（§588）。  
6. 「订金/保证金/押金」未约定定金性质 → 不适用定金罚则（解释§67）。

### 示例 E

- S = 500,000 元；约定定金 150,000  
- 20% × S = 100,000 → **仅 100,000 产生定金效力**；超出 50,000 不产生定金效力（可按预付款等性质分析）。

### 示例 F（罚则）

- 有效定金 100,000；收受方违约 → 应双倍返还 **200,000**（含原定金）。
