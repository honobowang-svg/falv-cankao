# 公司与商事 / 知产 · 文书模板（骨架）

> 仅供参考骨架；正式使用须由当事人或执业律师按案情填写并核管辖。

---

## 1. 股东知情权（查账）书面请求

```
股东查阅会计账簿、会计凭证请求书

致：××有限公司

本人系贵公司股东（持股比例____%，认缴/实缴____）。现依《公司法》第五十七条，书面请求查阅贵公司会计账簿、会计凭证。

查阅目的：（说明正当目的，例如了解公司财务状况、核实利润分配等）

查阅范围与期间：____年__月__日至____年__月__日之会计账簿、会计凭证。

请贵公司自收到本请求之日起十五日内书面答复；无正当理由不得拒绝。若拒绝，请书面说明理由。贵公司拒绝或逾期不答复的，本人将依法向人民法院提起诉讼。

股东：________（签名）
联系方式：________
日期：____年__月__日
```

## 2. 知识产权侵权告知函（停止侵权）

```
侵权告知函 / 律师函（可由权利人自行发出的告知骨架）

致：________

权利人________依法享有________（著作权/商标权/专利权）权属证明：________。

现发现贵方于________实施________行为，涉嫌侵犯上述权利。请于收到本函之日起__日内：
1. 立即停止侵权；
2. 下架/删除相关内容并销毁侵权复制品；
3. 书面回复处理结果。

若逾期未予改正，权利人将依法申请行政查处或提起诉讼，并主张停止侵害、赔偿损失及合理开支等（具体数额由有权机关认定，本函不作承诺）。

权利人/代理人：________
日期：________
附件：权属证明、侵权证据清单
```
