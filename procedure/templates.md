# 诉讼程序 · 文书模板（骨架）

---

## 1. 民事起诉状（通用）

```
民事起诉状

原告：……
被告：……

诉讼请求：
1. ……
2. 诉讼费用由被告负担。

事实与理由：
……

此致
××人民法院

起诉人：________
日期：________
附：证据清单及身份材料
```

---

## 2. 民事答辩状

```
民事答辩状

答辩人：……
被答辩人：……

答辩请求：驳回原告诉讼请求 / ……

事实与理由：
（针对起诉事实逐项答辩）

此致
××人民法院

答辩人：________
日期：________
```

---

## 3. 民事上诉状

```
民事上诉状

上诉人（原审×告）：……
被上诉人（原审×告）：……

上诉请求：撤销或变更××人民法院（XXXX）××号民事判决第×项……

上诉理由：
……

一审文书文号：…… 送达日期：……（注意判决15日/裁定10日）

此致
××中级人民法院（通过原审法院转）

上诉人：________
日期：________
```

## 4. 财产保全申请书

```
财产保全申请书

申请人：……
被申请人：……

请求事项：冻结/查封被申请人价值人民币____元的财产（账号/房产等线索）。

事实与理由：……
担保方式：……

此致
××人民法院

申请人：________
日期：________
```

---

## 5. 强制执行申请书

```
强制执行申请书

申请人：……
被申请人：……

请求事项：强制执行××人民法院（XXXX）××号生效法律文书，被申请人应给付……

事实与理由：文书已生效；履行期限已届满；被申请人未履行。申请执行期间为二年，起算……

此致
××人民法院

申请人：________
日期：________
附：生效文书副本、送达证明等
```
