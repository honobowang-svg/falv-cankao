# 婚姻家事 · 计算器（公式与示例）

> 核对基准日：2026-11-02（Asia/Shanghai）  
> 抚养费比例已按《婚姻家庭编解释（一）》第四十九条官文写死；最终仍以法院判决或双方协议为准。

---

## 1. 离婚冷静期时间线（协议离婚）

**依据**：`民法典` 第1076–1078条。

| 节点 | 规则 |
|------|------|
| T0 | 双方亲自到婚姻登记机关申请离婚登记 |
| T0～T0+30日 | 冷静期；任一方可撤回 |
| T0+30日～T0+60日 | 双方须亲自申请领证；未申请视为撤回 |
| 领证 | 登记机关审查后发给离婚证 → 婚姻解除 |

**示例**：2026-03-01 申请 → 冷静期至 2026-03-31；须在约 2026-04-01 至 2026-04-30 内双方亲自申请领证。

## 2. 抚养费估算

**依据**：

- `民法典` 第1085条（数额由协议或判决确定）  
- **`婚姻家庭编解释（一）`（法释〔2020〕22号）第四十九条**【已核实】

### 法定比例口径（写死自原文）

1. 数额可根据**子女实际需要、父母双方负担能力、当地实际生活水平**确定。  
2. **有固定收入的**，抚养费一般可以按给付方**月总收入的百分之二十至三十**给付。  
3. **负担两个以上子女**的，比例可以适当提高，但**一般不得超过月总收入的百分之五十**。  
4. **无固定收入的**，可依据当年总收入或者同行业平均收入，参照上述比例确定。  
5. **有特殊情况的**，可以适当提高或者降低上述比例。

另：抚养费包括生活费、教育费、医疗费等（解释（一）第四十二条）；一般给付至十八周岁（第五十三条）；增加抚养费情形见第五十八条；离婚协议约定不负担抚养费后的例外见解释（二）第十六条。

### 参考公式

**月抚养费 F ≈ 给付方月总收入 × 比例**

- 单子女常见试算区间：**20%～30%**（落在法定「一般」区间内）  
- 多子女：可高于 30%，但试算时提示「一般不超过 50%」上限口径  
- 特殊情况：明示可上浮/下浮，不作国定微调公式

### 示例 A

- 给付方月总收入 10,000 元；单子女；取区间中位假设 25%  
- **F ≈ 2,500 元/月**  
- 须同时说明：法院可按实际需要与当地生活水平在 20%～30% 内外调整（特殊情况）。

### 示例 B（变更 / 增加）

原协议 2,000 元/月；子女升学或患病致实际需要显著超过原定数额 → 可依解释（一）第五十八条及民法典第1085条第2款请求增加；增加幅度个案裁量。

### 示例 C（协议约定不负担后请求支付）

离婚协议约定直接抚养方负担全部抚养费、另一方不负担 → 对双方有约束力；但直接抚养方经济状况显著恶化或子女必要费用显著增加时，子女可请求另一方支付，数额综合考虑协议整体、需要、负担能力、当地生活水平（解释（二）第十六条）。

## 3. 共同财产分割（无固定算术公式）

**依据**：`民法典` 第1087、1092条；指导案例66号；解释（二）第五～八条等。

### 原则算法（定性）

1. 先剥离**个人财产**（第1063条）与共同财产（第1062条及解释（一）第25、26条）。  
2. 协议优先；不成则法院按**照顾子女、女方、无过错方**判决。  
3. 存在隐藏、转移、挥霍（含符合解释（二）第六条的网络打赏）等 → 可对过错方 **少分或不分**。

### 示例 D（转移存款·对照指导案例66号精神）

- 一方转移共同存款且不能合理说明  
- 法院可判令其向另一方补偿显著份额（指导案例中改判支付 12 万元等——**个案事实不同不得直接套数字**）。

**估算话术**：在双方贡献相当且无过错时，净共同财产常接近均分；有第1091条过错或第1092条转移情节时，无过错方可争取更高比例。

## 4. 离婚损害赔偿

**依据**：`民法典` 第1091条；解释（一）第八十六条～第九十条。

- 包括物质损害与精神损害；精神损害适用精神损害赔偿司法解释。  
- **无国定法定计算公式**；须在离婚诉讼框架内依法提出（见解释（一）第八十七条、第八十八条）。  
- 双方均有过错时，对损害赔偿请求不予支持（第九十条）。  
- 具体金额区间属实证统计，本库不写死。

---

## 5. 家务补偿 / 经济帮助

**依据**：民法典第1088、1090条；解释（二）第二十一条、第二十二条。

- 家务补偿：可综合负担义务投入的时间精力及影响、给付方负担能力、当地居民人均可支配收入等确定数额。  
- 经济帮助：年老、残疾、重病等生活困难，结合另一方财产状况酌定。  
- **无统一国标算术公式**。

## 6. 彩礼返还估算（定性，无固定返还比例公式）

**依据**（均已核实）：

- 解释（一）第五条  
- 法释〔2024〕1号（全文）

### 决策树（诉前提示）

1. **借婚姻索取财物** → 应予返还（规定第二条）。  
2. **先认定是否属于彩礼**（规定第三条；节日小额礼物、日常感情消费等一般不属于）。  
3. **未登记结婚**：  
   - 解释（一）第五条第一项可支持返还；  
   - 若**已共同生活**，依规定第六条综合实际使用、嫁妆、共同生活及孕育、过错、习俗确定**是否返还及比例**（无国定百分比）。  
4. **已登记但确未共同生活**，或**婚前给付致给付人生活困难**（且以离婚为条件）→ 解释（一）第五条第二、三项。  
5. **已登记且已共同生活**：一般不支持返还；但**共同生活较短且彩礼过高** → 规定第五条综合因素酌定是否返还及比例。「过高」考虑给付方所在地居民人均可支配收入、家庭经济情况、当地习俗。

**智能体禁止**：编造「返还 70%/50%」等未见于官文的固定比例。
