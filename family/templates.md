# 婚姻家事 · 文书模板

> 仅供参考；各地法院/民政格式可能不同。

---

## 模板 1：民事起诉状（离婚纠纷）

```text
民事起诉状

原告：姓名：________ 性别：__ 民族：__ 出生日期：________
身份证号：________________ 住址：________________ 电话：________

被告：姓名：________ 性别：__ 民族：__ 出生日期：________
身份证号：________________ 住址：________________ 电话：________

案由：离婚纠纷

诉讼请求：
一、依法判令解除原告与被告的婚姻关系；
二、依法判令婚生子女________由________直接抚养，被告/原告每月支付抚养费______元至子女年满十八周岁（或独立生活时止）；
三、依法分割夫妻共同财产：……（列明房屋、存款、车辆等）；
四、依法判令被告支付离婚损害赔偿______元（如有法定过错）；
五、诉讼费用由被告负担。

事实与理由：
原告与被告于____年__月__日登记结婚，……（感情情况、分居、子女、财产、过错事实）。
根据《中华人民共和国民法典》第一千零七十九条、第一千零八十四条、第一千零八十五条、第一千零八十七条等规定（条号按实际请求调整），提起本案诉讼。

证据目录：结婚证、子女出生证明、财产线索、出警记录/病历、聊天记录等。

此致
________人民法院

具状人：________
日期：____年__月__日
```

## 模板 2：离婚协议书（协议离婚用）

```text
离婚协议书

男方：________ 身份证号：________
女方：________ 身份证号：________

男女双方于____年__月__日在________登记结婚，现因________自愿离婚，经协商达成如下协议：

一、双方自愿离婚。
二、子女抚养：子女________由________直接抚养；另一方每月支付抚养费______元，于每月__日前支付；探望方式：________。
三、财产分割：……（房屋归属与补偿、存款、车辆、公积金、股权等）。
四、债务处理：……（共同债务承担方式）。
五、双方保证协议内容真实，无隐藏、转移财产；若发现隐藏转移，自愿少分或不分并承担法律责任。
六、本协议一式三份，双方各持一份，婚姻登记机关一份。

男方签字：________ 女方签字：________
日期：____年__月__日
```

## 模板 3：人身安全保护令申请书

```text
人身安全保护令申请书

申请人：________ 性别：__ 住址：________ 电话：________
被申请人：________ 性别：__ 住址：________ 电话：________

请求事项：
一、禁止被申请人实施家庭暴力；
二、禁止被申请人骚扰、跟踪、接触申请人及其相关近亲属；
三、责令被申请人迁出申请人住所（如适用）；
四、其他：________

事实与理由：
……（家暴时间、方式、出警、伤情、现实危险）。依据《反家庭暴力法》第二十三条、第二十九条等规定提出申请。

此致
________人民法院

申请人：________
日期：____年__月__日
附件：出警记录、告诫书、病历、照片、证人线索等
```
